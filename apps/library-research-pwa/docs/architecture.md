# معماری نسخه ۰٫۱

## ۱. محدوده اجرا

برنامه در پوشه مستقل `apps/library-research-pwa/` قرار می‌گیرد. هیچ فایل عملیاتی قبلی در این مرحله تغییر داده نشده است. منبع داده نسخه نخست، IndexedDB روی همان مرورگر/دستگاه است؛ GitHub فقط محل نگهداری کد و اسناد است و پایگاه داده عملیاتی یا میزبانی اطلاعات محرمانه نیست.

## ۲. تصمیم فنی نسخه نخست

مأموریت، React/Vite/TypeScript را به‌عنوان پشته پیشنهادی معرفی می‌کند و در عین حال تطبیق فناوری با وضعیت واقعی مخزن را لازم می‌داند. در این مرحله TypeScript و ES Modules بومی مرورگر انتخاب شده‌اند و React/Vite اضافه نشده‌اند، به دلایل زیر:

1. هیچ برنامه مستقل PWA یا زنجیره ساخت React/Vite در مخزن وجود نداشت.
2. نسخه نخست به یک رابط محدود و فرم‌محور نیاز دارد؛ React در این دامنه ضرورت فنی اثبات‌شده‌ای ایجاد نمی‌کند.
3. هدف آفلاین و کم‌وابستگی است؛ برنامه در زمان اجرا به CDN، فونت خارجی، API شخص ثالث یا بسته JavaScript بیرونی نیاز ندارد.
4. در محیط ساخت این نوبت دسترسی به npm registry برقرار نبود؛ افزودن وابستگی‌های نصب‌نشده و اعلام تست موفق آن‌ها قابل قبول نبود.
5. TypeScript با کامپایلر 5.8.3 موجود به JavaScript استاندارد تبدیل می‌شود و فایل‌های حاصل به‌صورت ایستا قابل میزبانی‌اند.

این تصمیم، انتخاب دائمی فناوری برای نسخه نهایی مرکز اسناد نیست. اگر تعداد صفحات، پیچیدگی تعامل‌ها یا نیاز تیم نگهداری افزایش یابد، مهاجرت به Vite/React می‌تواند در شاخه و مرحله مستقل بررسی شود. در آن صورت باید زنجیره ساخت و آزمون واقعی برقرار باشد.

## ۳. لایه‌ها

- **ارائه:** `index.html`, `styles.css` و `src/app.ts`؛ رابط فارسی و راست‌به‌چپ.
- **منطق دامنه:** `src/domain.ts`؛ نرمال‌سازی فقط برای جست‌وجو، اعتبارسنجی دسته و محل، شناسه و برچسب وضعیت.
- **داده:** `src/db.ts`؛ دسترسی IndexedDB و تراکنش‌های موجودیت‌ها.
- **مدل:** `src/model.ts`؛ تعریف ساختار Book، Copy، Martyr، Link، Extracted Item و منبع خام.
- **ورود Excel:** `src/xlsx.ts`؛ خواندن ساختار OOXML محلی در مرورگر.
- **پشتیبان:** `src/backup.ts`؛ JSON کامل، بازیابی افزایشی و CSV.
- **آفلاین:** `sw.js`؛ cache پوسته و فایل‌های ثابت، نه داده‌های کاربر.

ناوبری اصلی در نسخه نخست پنج ورودی دارد: خانه، کتابخانه، شهدا، جست‌وجوی محلی و پژوهش/بررسی. تنظیمات، صف بازبینی و ورود Excel از صفحه‌های فرعی باز می‌شوند تا نوار اصلی شلوغ نشود.

## ۴. دو مفهوم جدا

- اثر کتاب‌شناختی و نسخه فیزیکی شناسه‌های مستقل دارند.
- محل فیزیکی فیلدی از نسخه فیزیکی است و تاریخچه جابه‌جایی را نگه می‌دارد.
- پرونده شهید و نشانی مزار از رابطه کتاب–شهید مستقل‌اند.
- ارتباط و یادداشت پژوهشی دارای وضعیت بررسی مستقل‌اند.
- وجود رکورد، تأیید صحت و مجوز انتشار یک وضعیت واحد نیستند.

## ۵. چرخه ورود Excel

انتخاب فایل → محاسبه SHA-256 → خواندن فهرست شیت‌ها → انتخاب شیت و ردیف سرستون → پیش‌نمایش → ذخیره خام ردیف‌ها برای بررسی. رابط نگاشت دستی ستون‌ها هنوز در نسخه ۰٫۱ پیاده‌سازی نشده و هیچ تبدیل خودکار به موجودیت‌های نهایی انجام نمی‌شود.

در این نسخه هیچ سطر Excel به‌صورت خودکار به Books، Martyrs یا Links منتقل نمی‌شود. این مرز تا زمان ممیزی فایل مرجع و تصویب نگاشت حفظ می‌شود.

## ۶. چرخه پشتیبان

خروجی JSON شامل شماره نسخه ساختار و همه storeهاست. بازیابی فقط شناسه‌هایی را اضافه می‌کند که از قبل وجود ندارند؛ شناسه تکراری بدون بازنویسی کنار گذاشته می‌شود. در این نسخه حذف انبوه یا ادغام خودکار وجود ندارد.

## ۷. میزبانی

برای نصب PWA، برنامه باید از یک مبدأ HTTPS در دسترس دستگاه Android ارائه شود. میزبانی عمومی GitHub Pages، انتشار اطلاعات واقعی، یا اتصال مستقیم به سایت زنده در محدوده این مرحله نیست. زیرساخت داخلی مرکز اسناد در مرحله بعد بررسی می‌شود.


## ۸. پوسته و تایپوگرافی

- پوسته بصری در فایل مستقل `theme.css` قرار دارد تا از منطق داده و کد دامنه جدا بماند.
- `scripts/loader.js` ابتدا stylesheet پایه و سپس پوسته محلی را بارگذاری می‌کند.
- فونت متغیر Vazirmatn با مجوز SIL OFL 1.1 در پوشه fonts همراه برنامه است؛ Loader آن را محلی ثبت می‌کند و Service Worker فایل را cache می‌کند. فونت‌های فارسی نصب‌شده دیگر fallback هستند؛ Tahoma/Arial و درخواست CDN وجود ندارد.
- فایل پوسته در APP_SHELL ذخیره می‌شود و نام cache نسخه‌گذاری شده است؛ داده‌های عملیاتی کاربر همچنان cache نمی‌شوند.
- تغییر رنگ‌ها و تایپوگرافی، مدل داده و فایل مرجع Excel را تغییر نمی‌دهد.

## ۹. پیمایش ارتباط‌ها

روابط کتاب و شهید در نمای کتابخانه، نمای شهدا و نتایج جست‌وجو در هر دو جهت قابل مشاهده‌اند. وضعیت هر ارتباط (پیشنهادی، تأییدشده یا ردشده) مستقل نمایش داده می‌شود؛ نمایش یک رابطه به معنی تأیید آن نیست.
