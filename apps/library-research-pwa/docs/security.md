# حفاظت داده و کنترل انتشار نسخه ۰٫۱

- همه داده‌های عملیاتی در IndexedDB مرورگر همین دستگاه می‌مانند.
- Service Worker فقط پوسته برنامه و فایل‌های ثابت را cache می‌کند؛ پایگاه داده IndexedDB در Cache Storage قرار نمی‌گیرد.
- کد برنامه از CDN، فونت خارجی، API بیرونی، Supabase یا وب‌سایت گلزار درخواست نمی‌زند.
- برای استفاده با داده واقعی، مبدأ HTTPS و حفاظت فیزیکی دستگاه لازم است.
- نسخه فعلی احراز هویت یا کنترل دسترسی چندنقشی ندارد؛ مناسب استفاده چندکاربره یا دستگاه مشترک نیست.
- پاک‌شدن داده مرورگر، خرابی دستگاه یا حذف فضای سایت می‌تواند داده محلی را از بین ببرد؛ پشتیبان JSON منظم ضروری است.
- فایل پشتیبان شامل اطلاعات داخلی است و باید در محل امن و مجاز نگهداری شود.
- شناسه‌های موجود در بازیابی بازنویسی نمی‌شوند؛ تعارض‌ها گزارش می‌شوند.
- حذف انبوه و ادغام خودکار وجود ندارد.
- هر کتاب، نسخه، شهید، رابطه و یادداشت در ثبت اولیه داخلی/نیازمند بررسی است.
- تأیید انسانی یک ارتباط یا یادداشت، مجوز انتشار عمومی نیست؛ وضعیت انتشار به‌صورت مسدود باقی می‌ماند.
- هیچ داده‌ای به `golzarteh.ir`, GitHub Pages, Supabase یا سرویس بیرونی ارسال نمی‌شود.

## پیش از بهره‌برداری

نیازمند بررسی امنیتی و عملیاتی شامل HTTPS داخلی، سیاست پشتیبان‌گیری، رمزگذاری دستگاه، چندنقشی/احراز هویت، بازیابی آزمایشی، سطح دسترسی، Audit Log کامل و ارزیابی حقوق انتشار است.
