# انتشار مستقیم با GitHub Pages

این برنامه از همان مخزن عمومی `forog1980-star/book` منتشر می‌شود؛ Vercel در مسیر ساخت یا میزبانی آن دخالت ندارد.

## نشانی‌ها

- برنامهٔ اصلی: https://forog1980-star.github.io/book/
- کتابخانه و پژوهش: https://forog1980-star.github.io/book/library-research/
- نسخهٔ سریع موجودی: https://forog1980-star.github.io/book/library-quick-inventory.html

## ساخت و استقرار

- کد، آزمون‌ها و مستندات نسخهٔ مستقل در `apps/library-research-pwa/` نگهداری می‌شود.
- گردش‌کار `.github/workflows/library-research-pwa.yml` ساخت، آزمون واحد، آزمون مرورگر Chromium و بستهٔ ایستا را بررسی می‌کند.
- گردش‌کار `.github/workflows/deploy.yml` ابتدا برنامهٔ اصلی را می‌سازد، سپس PWA را با Node.js 22 می‌سازد و خروجی پاک آن را در `dist/library-research/` قرار می‌دهد.
- خروجی نهایی GitHub Pages شامل برنامهٔ قبلی و مسیر مستقل PWA است؛ فایل‌های منبع، آزمون و مستندات PWA به‌عنوان دارایی قابل اجرا در مسیر عمومی کپی نمی‌شوند.
- فونت Vazirmatn و مجوز SIL OFL همراه PWA هستند و بارگذاری فونت از CDN لازم نیست.

## حفاظت و حدود انتشار

- PWA در این نسخه داده‌ها را در IndexedDB همان مرورگر نگهداری می‌کند؛ هیچ اتصال یا نوشتنی در Supabase انجام نمی‌شود.
- ساخت بستهٔ خود PWA، workbook، CSV، source، test و docs را وارد خروجی همان PWA نمی‌کند.
- فایل‌های قبلی مخزن، از جمله خروجی‌ها، دارایی‌ها و داده‌های موجود، در این تغییر جایگزین یا حذف نمی‌شوند.
- انتشار برنامه به‌معنی مجوز انتشار عمومی محتوای آرشیوی یا ورود دادهٔ محرمانه نیست.
- آزمون CI در Chromium شبیه‌سازی‌شده است؛ نصب و آزمون نهایی روی گوشی Android واقعی همچنان باید روی دستگاه هدف انجام شود.
