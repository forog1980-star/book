# سامانه مدیریت کتابخانه و پژوهش مرکز اسناد گلزار شهدای تهران

نسخه توسعه ۰٫۲ — برنامه مستقل محلی؛ آزمون‌های واحد و Chromium و بسته استقرار پاک در CI موفق؛ انتشار مستقیم GitHub Pages با مخزن `forog1980-star/book` انجام می‌شود. نصب و آزمون Android واقعی همچنان نیازمند بررسی روی دستگاه هدف است.

این برنامه در پوشه مستقل apps/library-research-pwa ساخته شده است. به ابزار قبلی، فایل Excel مرجع، وب‌سایت زنده یا Supabase متصل نیست.

## قابلیت‌های نسخه نخست
- رابط فارسی/RTL و موبایل‌محور با پوسته PWA.
- ذخیره محلی IndexedDB.
- تفکیک اثر کتاب‌شناختی و نسخه فیزیکی و شناسه مستقل.
- دسته‌های R/A/H/P/K/M، قفسه‌های SH-01 تا SH-04 و طبقات T01 تا T06.
- تاریخچه تغییر محل جلد، پرونده شهید، اطلاعات مزار، روابط کتاب–شهید و یادداشت پژوهشی با ارجاع صفحه خام.
- صف بررسی انسانی؛ انتشار عمومی محتوای آرشیو مسدود.
- جست‌وجوی محلی فارسی، پشتیبان کامل JSON، بازیابی افزایشی و CSV.
- ورود خام XLSX همراه با اثر انگشت و منشأ شیت/ردیف؛ نگاشت دستی ستون‌ها و پیش‌نمایش اضافه شده‌اند، اما ساخت رکورد نهایی همچنان خودکار نیست.

## ساخت و اجرای محلی
در PowerShell:
1. npm install
2. npm test
3. npm run build
4. npm run serve

نشانی محلی همان دستگاه: http://127.0.0.1:4173/
برای نصب روی Android باید برنامه روی HTTPS یا دامنه داخلی امن در دسترس باشد.

منابع TypeScript و ماژول‌های runtime به صورت gzip نگهداری می‌شوند. Build آن‌ها را باز کرده، کامپایل می‌کند و خروجی مرورگر را مجدداً فشرده می‌سازد. برنامه در زمان اجرا به CDN یا API بیرونی نیاز ندارد.

## محدودیت و آزمون
- نگاشت نهایی ستون‌ها هنوز تصویب و اجرا نشده است.
- احراز هویت، چندکاربره، همگام‌سازی مرکزی، OCR، AI و جست‌وجوی اینترنتی هنوز ساخته نشده‌اند.
- کامپایل TypeScript، ۱۱ آزمون واحد، ۱۵ دارایی HTTP و سناریوهای Chromium در GitHub Actions موفق‌اند (Node.js 22).
- آزمون تعاملی در Chromium و شبیه‌سازی حالت آفلاین در CI انجام شده است. نصب PWA، قطع کامل شبکه، بازگشایی Chrome و دوام داده پس از راه‌اندازی مجدد روی Android واقعی و آزمون ۱۰ تا ۲۰ کتاب واقعی هنوز انجام نشده‌اند.
- تا تکمیل آزمون میدانی، این نسخه برای بهره‌برداری سازمانی یا داده محرمانه توصیه نمی‌شود.

اسناد معماری، مدل داده، امنیت، ورود Excel، آزمون، راهنمای کاربری، [طراحی بصری](docs/visual-design.md) و [چک‌لیست آمادگی انتشار](docs/release-readiness.md) در پوشه docs قرار دارند.


## بازبینی رابط و طراحی بصری — ۱۴۰۵/۰۸/۱۰

- پالت گرم کاغذی/سفالی با زمینه روشن، سطح‌های کم‌کنتراست و رنگ‌های وضعیت کنترل‌شده در `theme.css` تعریف شده است.
- رنگ PWA، manifest و آیکن با پالت هماهنگ‌اند؛ فایل پوسته در Service Worker cache می‌شود.
- فونت متغیر Vazirmatn با مجوز SIL OFL 1.1 در پوشه fonts بسته‌بندی و به‌صورت محلی بارگذاری می‌شود؛ Tahoma و Arial استفاده نمی‌شوند و فونت CDN وجود ندارد.
- در فهرست کتاب‌ها، پرونده شهدا و نتایج جست‌وجو، ارتباط‌های ثبت‌شده از هر دو سمت قابل مشاهده‌اند؛ وضعیت هر ارتباط نیز کنار آن نمایش داده می‌شود.
- هنگام جابه‌جایی جلد، محل ناسازگار با دسته موضوعی هشدار می‌دهد و ثبت محل واقعی با تأیید کاربر ممکن است.
- جزئیات پالت و تایپوگرافی در [راهنمای طراحی بصری](docs/visual-design.md) آمده است.

این تغییرها هنوز به معنی تأیید ظاهر در Android یا آمادگی بهره‌برداری نیستند؛ نتیجه CI و آزمون‌های واقعی دستگاه باید جداگانه ثبت شوند.


## به‌روزرسانی رابط و موانع انتشار — ۱۴۰۵/۰۸/۱۰

- پالت به کرم کاغذی/سفید و بژ ملایم تغییر کرده است؛ متن‌ها از مشکی خالص استفاده نمی‌کنند.
- پشته فونت به Vazirmatn محلی، IRANSansX، IRANYekanX، Estedad، Sahel، Shabnam و Noto محدود است؛ Tahoma/Arial حذف‌اند. فایل Vazirmatn و مجوز OFL آن در برنامه محلی است.
- فرم ویرایش مشخصات کتاب اضافه شده است؛ شناسه، وضعیت بررسی و نسخه‌های فیزیکی حفظ می‌شوند.
- رابط نگاشت دستی ستون‌های Excel اضافه شده؛ نگاشت همراه منشأ بسته خام ذخیره می‌شود، اما هیچ رکورد نهایی خودکار تولید نمی‌شود.
- بازیابی JSON اکنون ابتدا فایل را اعتبارسنجی و شمارش storeها را پیش‌نمایش می‌کند؛ اجرای بازیابی نیازمند تأیید صریح است.
- آزمون Chromium در CI برای ثبت/ویرایش، IndexedDB، بازیابی و آفلاین، و فایل Excel مرجع اضافه شده است. نتیجه نهایی پس از اجرای GitHub Actions ثبت می‌شود.

انتشار محلی تک‌کاربره از بهره‌برداری داخلی چندکاربره و انتشار محتوای آرشیو جداست. نصب/آزمون Android واقعی همچنان شرط نهایی پایلوت روی گوشی است.
